
# 🏏 IPL Match Strategy & Venue Performance Analytics

An exploratory data visualization project built using **Tableau** to evaluate toss strategy efficacy, venue-by-venue scoring behaviors, and top-scorer production across IPL matches.

## 🔍 Key Insights
1. **Chasing Dominance:** In over 87% of matches where teams won the toss, they chose to bowl first, converting roughly 59% of those matches into wins[cite: 12].
2. **Defending vs. Chasing Grounds:** Venues like Jaipur and Wankhede produce high first-innings averages (>215), while chasing teams faced heavier attrition at grounds like Kolkata and Ahmedabad[cite: 13].
